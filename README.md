# 光之教堂 · Church of the Light — 安藤忠雄, 1989

一个自包含的实时 3D 网页场景：大阪茨木「光之教堂」（茨木春日丘教会）。
**双击 `Church-of-the-Light.html` 即可用浏览器打开**（three.js 已内联，无需联网、无需服务器）。

## 场景内容
- 一座 6.2 × 18 × 5.9 m 的清水混凝土盒子：四片独立的端墙（厚 24 cm）被两条 42 cm 宽的狭缝切成「光之十字」；
  西侧后部是一间门厅，门厅侧墙上开一道水平光缝，**东侧墙上就是真正可以走进去的门洞**（沿踏步石入院即达），
  入口前是那道著名的 15° 独立混凝土墙。
- 室内：橡木地板、木质长凳、讲台、石制洗礼盆、几个卡通人物。
- 太阳按真实方向投射：光穿过 24 cm 厚墙上的狭缝，在木地板、长凳与西墙上画出会随时刻移动的十字，
  并配有体积光柱与空气中的浮尘。
- 十字是一个**真正的洞口**：白天从外面看进去是一道深色的缝（能看到室内的长凳），
  夜里则向外发光，整栋建筑像一盏灯；室内看则是凹进 24 cm 的洞口，光从外面涌进来。

## 交互
| 操作 | 说明 |
| --- | --- |
| 拖拽 / 右键拖拽 / 滚轮 | 旋转 / 平移 / 缩放 |
| 数字键 1–4 | 晨曦 · 正午 · 黄昏 · 月夜 |
| R / A / I | 自动旋转 / 光之标注 / 说明面板 |
| 左下按钮 | 总览 · 入口 · 北立面 · 中殿 · 长凳 · 光之十字 · 近观 |

URL 参数：`?view=cross&mood=dusk&annot=1&nohud=1&still=1`（still 用于确定性截图）。

## 目录
```
src/00-core.js    渲染器、卡通材质、墨线描边、程序化混凝土/木材/辉光贴图
src/10-world.js   天空、光照、场地、教堂、室内、光缝与体积光
src/20-app.js     四种光线情绪、相机轨道、标注、UI、主循环
src/page.html     页面外壳（HUD / 说明面板 / 加载页）
build.mjs         把 three.js + 三个模块内联进单文件 HTML
shots.json        截图配置（shot.mjs 用）
```

## 重新构建
```bash
node build.mjs         # -> Church-of-the-Light.html
```
截图（需本机 Chrome）：
```bash
node shot.mjs "file:///<...>/Church-of-the-Light.html" shots.json
```
